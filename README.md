# E-Commerce Behavior Analytics & Recommendation System

An end-to-end data analytics project focused on analyzing large-scale e-commerce behavioral data and developing a personalized product recommendation system using implicit user interactions.

## Project Overview

The objective of this project is to understand how customers interact with products throughout the e-commerce journey and transform these behavioral signals into meaningful product recommendations.

The project covers:

- Exploratory Data Analysis (EDA)
- Customer behavior analysis
- Business metrics
- Feature engineering
- User-product interaction modeling
- Recommendation system development
- Power BI dashboard visualization

## Dataset

**Dataset:** E-Commerce Behavior Data from Multi-Category Store  
**Analysis Period:** October 2019

The dataset contains customer behavior events such as product views, cart additions, and purchases.

### Dataset Scale

| Metric | Value |
|---|---:|
| Total Events | 42.45M |
| Unique Users | 3.02M |
| Unique Products | 166.8K |
| Product Views | 40.78M |
| Cart Events | 926.5K |
| Purchase Events | 742.8K |

> The raw dataset is not included in this repository due to its large file size.

## Customer Funnel

The event-level funnel shows a significant difference between product discovery and stronger purchase-intent actions.

| Stage | Events | Conversion from View |
|---|---:|---:|
| View | 40.78M | 100% |
| Cart | 926.5K | 2.27% |

## Recommendation System

The recommendation engine uses **Item-Based Collaborative Filtering** based on implicit user feedback.

### Interaction Scoring

Different behavioral actions are assigned different weights:

- View = 1
- Cart = 3
- Purchase = 5

Stronger behavioral signals therefore contribute more heavily to the recommendation process.

### Model

**Algorithm:** K-Nearest Neighbors (KNN)  
**Similarity Metric:** Cosine Similarity  
**Approach:** Item-Based Collaborative Filtering

For computational efficiency, the model focuses on the **5,000 most interacted products**.

### Model Scale

| Metric | Value |
|---|---:|
| Model Users | 2.69M |
| Model Products | 5K |
| Model Interactions | 14.47M |

The model identifies products with similar user interaction patterns and uses these relationships to generate personalized recommendations.
